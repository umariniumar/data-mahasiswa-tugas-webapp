INFORMASI & SOURCE CODE

Kenali bagaimana aplikasi ini bekerja.

Pilih file di bawah untuk melihat kode yang digunakan. Halaman ini juga menjelaskan peran JavaScript dalam proses mengambil input, menghitung nilai, dan menentukan kelulusan.

index.html · Struktur halaman

Apa fungsi HTML?

HTML digunakan untuk membuat struktur atau kerangka halaman. Di aplikasi ini HTML membuat form nama, NIM, nilai Tugas, UTS, UAS, tombol hitung, dan area hasil.

style.css · Tampilan aplikasi

Apa fungsi CSS?

CSS mengatur warna, ukuran, jarak, layout, tombol, card, responsive design, dan visual halaman. Desainnya dibuat dengan pendekatan editorial minimal seperti referensi Buffer: background terang, grid tipis, tipografi besar, rounded card, dan aksen hijau.

script.js · Logika aplikasi

Bagaimana JavaScript digunakan?

JavaScript adalah bagian yang membuat halaman menjadi interaktif. Pada aplikasi ini, JavaScript melakukan empat proses utama:

  1. 1
    Mengambil input Nama, NIM, Tugas, UTS, dan UAS diambil dari elemen HTML menggunakan getElementById().
  2. 2
    Mengubah nilai menjadi angka Number() digunakan agar nilai input dapat dihitung sebagai angka.
  3. 3
    Menghitung nilai akhir JavaScript menerapkan bobot Tugas 30%, UTS 30%, dan UAS 40%.
  4. 4
    Menentukan kelulusan Jika nilai akhir lebih dari 75 maka tampil LULUS. Selain itu tampil TIDAK LULUS.
Nilai Akhir = (Tugas × 0.30) + (UTS × 0.30) + (UAS × 0.40)
